# Emmad.dev — Blazor portfolio

En responsiv portfolio på svenska byggd med Blazor Web App och .NET 8. Startsidan innehåller projekt med filter, detaljvisning, erfarenhet, kompetenser och kontaktlänkar.

## Kör lokalt

Kräver .NET 8 SDK.

```bash
dotnet run --project EmmadDev/EmmadDev.csproj
```

Öppna adressen som visas i terminalen. Projektfilter och detaljknappar är interaktiva och kontaktlänkarna öppnar e-post eller telefon i lämplig app.
